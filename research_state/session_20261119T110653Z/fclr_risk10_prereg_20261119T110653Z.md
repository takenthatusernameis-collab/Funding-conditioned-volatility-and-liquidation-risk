## Smallest defensible effect (preregistered decision rule)

Smallest defensible effect = minimum `mde_brier_80pct` across scored blocks at full instrument count (block_3 primary). An incremental Brier effect is defensible only if `>=` that MDE. Declare SUPPORT only if block_3 Brier improvement > 0 AND >= smallest defensible effect AND `p_raw < 0.05` AND `p_holm < 0.05` AND placebo 95th percentile < observed improvement. The concrete decision value is recorded in `fclr_risk10_power_*.json` after the MDE recompute.
