## Design

This is the first confirmatory use of the on-disk ironflow bulk observed-liquidation stream (Track A, RESEARCH_PROMPT.md section 3.2) to test whether funding-conditioned features predict observed liquidation intensity. It is NOT a re-run of the modeled Track B breach proxy.

The funding-conditioned VOLATILITY (QLIKE) pillar is already closed as a leakage-robust null (FCLR-POOLED-ROBUST-002: C2-B1 QLIKE +1.011%, Holm primary p=0.6365 vs alpha_2=0.00833). Per RESEARCH_PROMPT.md sections 16/19, work continues after unfavorable results. The remaining unfinished half of section 3.2 — do funding-conditioned features predict OBSERVED liquidation intensity? — is therefore the single highest-value unfinished task.

No risk overlay is built (RESEARCH_PROMPT.md section 9: forecast gate did not pass).

## Data

- `research_state/data_cache/ironflow_bulk/{candles_1h,funding,open_interest,liquidations}`, 18 months 2025-05..2026-10
- Every parquet read asserts the `.parquet.sha256` sidecar before use; caches are read-only
- No network, no new source, no overlay
- Liquidations schema: `timestamp, market, issuer, wallet, position_side, size, notional_usd, avg_price, fills, block, tx_hash`
- Example markets: `BTC-PERP`, `xyz:KIOXIA-PERP` (strip prefix/suffix to coin)

## Market-to-coin identity map

`liquidations.market 'XXX-PERP'` -> `coin 'XXX'` by stripping the `-PERP` suffix and any exchange prefix before the first `:`. Join to candles_1h/funding/open_interest on `coin` + UTC hour.

**Delisting-aware:** a coin is eligible at hour h only if it has a valid candle row at h. Coins seen but not present in the final coverage window form a separate **exited** sensitivity arm; survivors and exited are never merged.

## Targets

| Target | Definition |
|--------|------------|
| Primary count | Observed liquidation event count per coin-hour (wallet-level events deduped by `tx_hash` within the hour) |
| Primary notional | OI-normalized observed liquidation notional intensity = sum(`notional_usd`) / `open_interest_usd` per coin-hour |
| Secondary occurrence | Binary indicator of >=1 observed liquidation in the coin-hour (Brier/log-loss calibration) |
| Construction window | Outcome measured over forward 24h window t+1..t+24h; all predictors from data ending no later than t |

## Features

| Model | Features |
|-------|----------|
| B1 (RV-only baseline) | log_rv1h, log_rv24h, log_rv168h |
| C1 (funding-augmented) | B1 + signed funding rate + abs funding percentile (train-only 90-day lookback) |
| C2 (combined candidate) | C1 + mark/index premium + mark/EMA24 distance |

Scaling: training-only means/stds; zero-variance columns -> constant 0; missing features remain missing (never zero-filled or forward-filled).

## Splits

- Unit: one eligible linear perpetual coin x one fully closed UTC hourly timestamp
- Train: first 60% of distinct hourly timestamps
- Purge/embargo: 48 hours (d2 remediation from FCLR-POOLED-AUDIT-001)
- Test: distinct hourly timestamps after the 48h purge+embargo, grouped into **non-overlapping 168h forward blocks** (d10 remediation). An origin is admitted only if its full 24h forward window fits entirely inside one block.
- Uncertainty: per-coin block bootstrap, resampling complete UTC time blocks jointly across coins, seed 20261122, 2000 replicates

## Materiality floor

**Frozen at 2.0% relative reduction.** `materiality_met` iff the relative QLIKE/Poisson-deviance reduction of C2 vs B1 <= -2.0% (C2 at least 2% better than B1). The floor is never relaxed after outcomes.

## Metrics

- Primary: paired out-of-sample QLIKE difference (C2_vs_B1) and Poisson deviance difference on observed intensity targets, reported as absolute difference and relative % reduction
- Secondary: Brier score, log loss, calibration slope/intercept for occurrence
- RV/persistence baseline (B0) also reported for interpretability

## Multiplicity

Holm familywise-error correction across the declared family `{C2_vs_B1_primary_count, C2_vs_B1_primary_notional, survivors_arm, exited_arm}`. Report raw and Holm-adjusted p; the whole family is disclosed.

## Alpha-spending

Sequential confirmatory look k=2 with alpha-spending: alpha_k = 0.05/(k*(k+1)) = 0.05/6 = 0.008333 (RESEARCH_PROMPT.md section 17).

## Decision rule

- **SUPPORTED** iff `materiality_met` AND bootstrap CI95 upper bound < 0 AND Holm-adjusted primary p < alpha_2
- **PARTIAL_POSITIVE_SIGNAL** iff incomplete labels prevent a full census but directional signal is consistent
- **NOT_SUPPORTED** otherwise

Nulls are preserved honestly. Missing events from a capped feed are never labeled "no liquidation." Never claim a complete observed-liquidation census from a capped feed.

## Admissibility (RESEARCH_PROMPT.md section 15)

Observed-liquidation coverage/completeness and the market->coin identity map are audited **before** any outcome is inspected. Label admissibility is frozen before outcomes. Capped-sample check performed; missing events are not treated as zero.
